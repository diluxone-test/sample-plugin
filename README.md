# DiluxOne Sandbox

A toy WordPress plugin where [DiluxOne's shared workflows](https://github.com/DiluxOne/.github) are proved end to end (DiluxOne/.github#287, item 12) before a version of them reaches a real plugin. Nothing here is published: its release runs as a rehearsal.

`make pre-pr` runs what CI runs.

This repository runs [DiluxOne's engine](https://github.com/DiluxOne/.github) with diluxone-test's own configuration, in [diluxone-test/.github](https://github.com/diluxone-test/.github).
